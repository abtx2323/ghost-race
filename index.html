    Where are my logs?
    Claude Code
    Each session is a .jsonl file in ~/.claude/projects/, in a folder named after your project. List the newest with ls -t ~/.claude/projects/*/*.jsonl | head
    Codex CLI
    Sessions are saved as ~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl
    Gemini CLI
    Saved chats are in ~/.gemini/tmp/, in a chats folder for each project.
    OpenAI Agents SDK, OpenTelemetry and anything else
    See the format guide for how to export traces, or write a small .ghost.json file.
    Race two agents with one command
    In your project, run npx github:abtx2323/ghost-race race "your task". It runs Claude Code and Codex side by side in separate git worktrees and opens the race here.
    Can't see the folder?
    Folders starting with a dot are hidden. On a Mac, press Cmd Shift G in the file picker and paste the path. On Windows, paste %USERPROFILE%\.claude\projects into the address bar.

    For a fair race, give each agent the same task in a fresh session.

    Share the race

    Clip shape

    The clip adds the start lights and the results card, about 22 seconds in total.

    A share link replays this race in anyone's browser. It holds ghost names, timings and tool types, never your commands, file names or prompts.

    Your logs never leave this device. Ghost Race runs entirely in your browser, and file names and commands stay hidden in clips unless you turn them on.
